# Meta tab — cron setup

The Meta tab reads `web/static/meta.json`, which is generated by `web/export_meta.py`.
This file should be regenerated daily so the meta stays current.

## Generate manually

```bash
python -m web.export_meta
# or with explicit formats/count:
python -m web.export_meta --format modern --format standard --count 30
```

Run from the repo root. Requires `web_static_dir` set in `~/.mtg_manager/config.toml`.

## Oracle VM — systemd timer

Create two files on the VM:

**`/etc/systemd/system/mtg-meta.service`**
```ini
[Unit]
Description=MTG Manager meta export

[Service]
Type=oneshot
WorkingDirectory=/home/ubuntu/mtg-manager
ExecStart=/home/ubuntu/mtg-manager/venv/bin/python -m web.export_meta --format modern --format standard --count 30
User=ubuntu
```

**`/etc/systemd/system/mtg-meta.timer`**
```ini
[Unit]
Description=Run MTG meta export daily

[Timer]
OnCalendar=*-*-* 03:00:00
Persistent=true

[Install]
WantedBy=timers.target
```

Enable:
```bash
sudo systemctl enable --now mtg-meta.timer
sudo systemctl start mtg-meta.service   # run immediately to populate the file
```

## Notes

- The script calls Goldfish for each format — expect ~2–3 minutes per format at 30 decks with the default 1 s delay.
- Card images are **not** downloaded by this script; existing images from `export_static` are reused. Cards not in your collection fall back to the Scryfall API live in the browser.
- Run after `mtg sync` so ownership counts reflect the latest collection.
